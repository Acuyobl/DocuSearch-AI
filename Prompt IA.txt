OBJETIVO DEL PROYECTO

Crear una plataforma inteligente de gestión documental que permita a organizaciones almacenar, clasificar, transcribir, indexar y consultar documentos PDF mediante inteligencia artificial, OCR y búsqueda avanzada.

La aplicación debe ofrecer una experiencia de usuario similar a Google para localizar información contenida dentro de documentos.

MÓDULOS PRINCIPALES

1. LOGIN

Pantalla profesional con:

- Usuario
- Contraseña
- Recuperar contraseña
- MFA
- Logo corporativo

2. DASHBOARD PRINCIPAL

Indicadores:

- Total documentos
- Documentos recientes
- Documentos pendientes
- Usuarios activos
- Búsquedas realizadas
- Alertas

Gráficos:

- Documentos por departamento
- Documentos por tipo
- Tendencias de uso
- Documentos más consultados

3. GESTIÓN DOCUMENTAL

Permitir:

- Arrastrar PDF
- Carga masiva
- Validaciones
- Vista previa
- OCR automático
- Extracción de texto
- Detección de idioma

Metadatos:

- Código
- Título
- Autor
- Departamento
- Categoría
- Fecha
- Nivel de confidencialidad
- Versión

4. OCR E IA

Al cargar un documento:

- Detectar si es PDF o escaneado
- Extraer texto
- Generar resumen inteligente
- Detectar palabras clave
- Extraer fechas
- Extraer entidades
- Clasificar automáticamente el documento

5. BUSCADOR TIPO GOOGLE

Barra central de búsqueda.

Debe permitir:

- Palabras clave
- Frases completas
- Filtros avanzados

Mostrar:

- Documento
- Página encontrada
- Fragmento relevante
- Relevancia

Opcional:

Búsquedas con lenguaje natural.

Ejemplos:

"Mostrar contratos firmados en 2025"

"Documentos relacionados con recursos humanos"

"Políticas de seguridad vigentes"

6. VISOR DOCUMENTAL

Características:

- Visualización PDF
- Resaltar coincidencias
- Navegación por páginas
- Comentarios
- Descarga según permisos

7. REPORTES

Generar:

- PDF
- Excel

Reportes:

- Documentos cargados
- Documentos por departamento
- Usuarios más activos
- Búsquedas realizadas
- Documentos más consultados
- OCR procesados

8. BITÁCORA DE AUDITORÍA

Registrar:

- Login
- Logout
- Búsquedas
- Descargas
- Modificaciones
- Eliminaciones

Mostrar:

- Usuario
- Fecha
- Acción
- Resultado
- Dirección IP
